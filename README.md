# 淮海战役 1948 · 战役沙盘

以《文章.jpg》（《华东野战军淮海战役攻击命令（节选）》，1948年11月4日）为史料起点，制作的可交互战役沙盘模拟器。写实军事地图风格，纯前端，无需安装依赖。

[GitHub 仓库](https://github.com/ling-shi-cyber/huaihai-1948) · [在线试玩](https://ling-shi-cyber.github.io/huaihai-1948/) · [下载 Windows 便携版](https://github.com/ling-shi-cyber/huaihai-1948/releases/latest)

在线试玩：https://ling-shi-cyber.github.io/huaihai-1948/

打开 `index.html` 即可游玩（推荐 Edge / Chrome，桌面端）。

## 一、这场战役

1948年11月6日至1949年1月10日，华东野战军、中原野战军在徐州—蚌埠地区对国民党军徐州“剿总”展开战略决战。战役分三个阶段：

1. **第一阶段（11.6—11.22）**：围歼黄百韬第7兵团于碾庄，攻占宿县切断徐蚌线，徐东阻援。
2. **第二阶段（11.23—12.15）**：围歼黄维第12兵团于双堆集，追击包围杜聿明集团于陈官庄。
3. **第三阶段（12.16—1.10）**：围而不歼、政治攻势，1月6日总攻，全歼杜聿明集团。

沙盘按真实地理与战斗序列建模：徐州、碾庄、运河车站、窑湾、曹八集、双堆集、陈官庄、宿县、蚌埠等 60 余处城镇，陇海、津浦铁路，大运河、沂河、浍河、涡河、淮河，以及华野 15 个纵队、中野 7 个纵队、国民党军 7 个兵团又 2 个绥靖区的军级单位。

## 三、玩法

### 基本操作

| 操作 | 说明 |
| --- | --- |
| 左键点击 | 选中部队 / 查看敌军 |
| Shift + 左键 | 多选 / 取消选择 |
| 左键拖框 | 框选我军部队 |
| 右键点击地图 | 行军（选中部队） |
| 右键点击敌军 | 攻击（选中部队） |
| 右键拖动 | 平移地图 |
| 滚轮 | 缩放（比例尺联动） |
| `E` | 执行本日 |
| `空格` | 自动推演 / 暂停 |
| `F` | 隐藏 / 显示侧栏 |
| `F11` / 地图右下角 ⛶ | 全屏 |
| `Tab` | 轮换选中我军部队 |
| `Esc` | 取消选择 / 取消指令；无选择时打开战役菜单 |
| `WASD` / 方向键 | 平移地图 |

选中部队后，右侧面板可下达：**行军、攻击、转入防御、构筑工事、就地休整、转进**。

### 每日回合

每一回合代表一天。玩家下达命令后点击“执行本日”，部队行军、交战，随后结算补给、士气、疲劳、工事与历史事件。

- **战斗**：攻击力取决于兵力、士气、补给、疲劳、地形与工事；多路合击、侧翼包抄、炮兵支援与指挥所靠近均有加成；渡河攻击、仰攻会受惩罚。
- **补给与包围**：补给依赖铁路、公路与后方基地，被切断补给的部队会逐日断粮、士气下降；被围部队可能投降或被歼。攻占宿县、徐州等枢纽可切断敌军补给。
- **工事**：防御每回合提高工事加成，最高 60%；“构筑工事”提升更快，但部队不能同时进攻。
- **战役行动**：每日获得指挥点，可发动 **炮火准备、夜间攻击、支前补给、政治攻势**。
- **历史事件**：贾汪起义、运河铁桥被炸、孙良诚投诚、攻占宿县、廖运周起义、徐州弃守、蒋介石空投手令、孙元良突围、政治攻势抉择等，会按时间/条件触发。
- **胜负**：三个阶段目标（歼敌、夺城、阻援）逐项评定；战役结束时按歼敌数、自身伤亡、目标达成度给出 S/A/B/C/D/F 评级，并与历史结果（歼敌 55.5 万、我军伤亡约 13.6 万）对照。

### 存档与继续战役

- **自动存档**：每次“执行本日”结算后自动写入“自动存档”槽；返回主菜单、退出游戏、关闭窗口/标签页时也会再存一次。
- **继续战役**：重新打开游戏时，主菜单会显示最近一次存档的缩略图、日期、阶段与双方兵力；点“继续战役”直接回到上次进度。
- **手动存档**：点顶栏右侧 **☰** 打开战役菜单，选择“保存进度”，使用 3 个手动存档位。保存时会弹出命名框（默认“存档 1 · 日期”，可改成“围歼黄百韬”这类名字）；已有存档可随时点“重命名”，自动存档同样可以命名，之后自动保存会保留这个名字。
- **读取 / 删除**：读取或删除存档都会二次确认；读取前当前进度会先写入自动存档。
- **退出游戏**：战役菜单中的“退出游戏”会先自动存档；桌面版随后关闭窗口，浏览器版回到主菜单。
- **存档位置**：浏览器版保存在本机 `localStorage`；桌面版保存在 WebView2 的用户数据目录（`%LOCALAPPDATA%\Huaihai1948`）。不上传、不联网。
- 战役结局也可以保存，之后点“查看战果”载入。

### 界面

- **顶栏**：日期、天气、阶段进度、双方总兵力对比、指挥点、执行/自动推演/战役菜单（☰）/战报/命令原文。
- **左栏**：作战序列（我军 / 敌军），可点击定位；红色圆点表示被围断粮。
- **地图**：程序化生成写实地形；部队标号带番号、兵力、士气/补给状态；选中后显示可达范围、命令箭头与目标。
- **右栏**：选中部队状态与命令、战役行动、阶段目标。
- **底栏**：战场通报；点击“全部战报”查看完整作战记录。
- **命令原文**：随时查看《文章.jpg》影印件与校订释文。

## 四、史料依据与处理

- 攻击命令原文、番号与作战地域，直接取自《文章.jpg》。
- 双方战斗序列、兵力、主官、日期、事件依据公开战史资料整理；兵力为约数，个别主官/番号在不同战史中存在异说（如第63军军长、第96军归属、黄百韬死因等），采用通行说法。
- 地图为大比例尺战区示意图，地理要素按真实相对位置与走向绘制，但为沙盘可玩性做了适度简化（如城镇间距、河宽、道路密度）。
- 天气按 1948 年 11—12 月淮海战场的一般情况编排：11 月上旬阴雨、12 月中旬起大雪严寒、1 月转晴冷。
- 战役结果可因玩家指挥而偏离历史；这正是沙盘推演的目的。

## 五、技术实现

- 纯 HTML / CSS / JavaScript，无第三方库、无网络请求。
- Canvas 2D：程序化绘制地形（噪声土壤、农田、丘陵晕渲、河湖、铁路/公路、城镇街区、村落树网），一次性烘焙为 2400×1400 底图。
- 地理内核 `js/geo.js`：栅格化河湖/桥梁/道路，Dijkstra 行军寻路、补给走廊泛洪、可达范围。
- 战役引擎 `js/engine.js`：逐日回合、双方 AI、战斗结算、补给/断粮/包围、士气/疲劳、工事、历史事件、目标与战果评定。可在 Node 中独立推演。
- 渲染 `js/render.js`：相机、城市铭牌避让、部队标号与堆叠偏移、命令箭头、战斗特效、天气粒子、比例尺。
- 界面 `js/ui.js`：作战序列、命令面板、战报、弹窗、抉择、战果、新手简报与作战手册。

## 六、Windows 桌面版

已打包为可分享的 Windows 应用：

- **直接下载**：[Releases 中的 Windows 便携版](https://github.com/ling-shi-cyber/huaihai-1948/releases/latest)（约 2.7 MB）
- 解压后双击 `淮海战役1948` 文件夹中的 **`淮海战役1948.exe`** 即可，无需安装。
- 从源码构建的产物在本地 `dist/` 目录（不提交到仓库），构建方法见 `desktop/`。

技术方案：WinForms + 系统 Microsoft Edge WebView2 运行时，游戏资源内置于 `web` 文件夹，窗口标题、图标、全屏（F11）均按桌面游戏处理。若系统 WebView2 不可用，程序会自动改用本机 Edge 的应用窗口（无地址栏）运行，功能一致；完全找不到浏览器时会给出提示。

桌面版同样支持自动存档 / 3 个手动存档 / 继续战役。关闭窗口时，外壳会先通知游戏写入自动存档再退出；存档保存在 WebView2 的用户数据目录 `%LOCALAPPDATA%\Huaihai1948`（兼容模式则保存在 Edge 应用配置目录）。

- 要求：Windows 10 / 11 64 位。
- 未做数字签名，首次运行如遇 SmartScreen，请点“更多信息 → 仍要运行”。
- 请保持 exe、三个 DLL 与 `web` 文件夹在同一目录。
- 构建源码与脚本见 `desktop/`，重新构建运行 `desktop/build.ps1`。

> 说明：开发环境的沙箱无法显示 Chromium 窗口，桌面外壳的 WebView2 最终画面未能在沙箱内目视验证；但打包后的网页资源已用无头浏览器完整验证（启动、指挥界面、史料图片、自动存档/继续战役/手动存档/读档/返回主菜单均通过），且外壳在 WebView2 不可用时会自动回退到 Edge。建议在本机双击 exe 做一次最终确认。

## 八、常见问题

- **打开后“开始指挥”等按钮无反应**：请按 `Ctrl + F5` 强制刷新一次。浏览器可能缓存了旧脚本；页面已为所有脚本加上版本参数，重新打开即可加载最新版本。
- **地图加载较慢**：首次打开需要在浏览器内程序化生成整个战区地形，通常 1–3 秒；加载遮罩消失后再点击“开始指挥”。
- **命令原文图片不显示**：确认 `文章.jpg` 与 `index.html` 位于同一目录。
